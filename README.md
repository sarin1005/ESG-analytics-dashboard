# ESG Analytics Dashboard

> **Business Analytics Industry Project**
> 
> This dashboard was developed as part of an industry collaboration through Business Analytics Industry Project.
> 
> An interactive Power BI dashboard designed to evaluate ESG performance using both quantitative operational metrics and qualitative sustainability assessments. The dashboard enables users to compare companies, analyse sector performance, explore ESG scores from different perspectives, and monitor an equal-weighted stock portfolio through an interactive interface.

---

## Project Overview

This project demonstrates an interactive ESG analytics dashboard developed to support the evaluation of companies from both quantitative and qualitative perspectives.

The dashboard enables the client to:

- Compare ESG performance across companies
- Analyse sector-level trends
- Explore company-specific ESG scores from different perspectives
- Monitor an equal-weighted portfolio index based on normalised stock prices

**Note:** To respect client confidentiality, company names and sensitive information have been anonymised.

## Business Problem

Many ESG assessments rely heavily on sustainability disclosures while providing limited insight into whether those disclosures are supported by operational evidence.

This project aims to improve ESG evaluation by integrating operational ESG performance, qualitative assessment, sector context, and market performance into a single interactive dashboard. The dashboard enables users to explore ESG performance from multiple perspectives while supporting transparent comparison across companies and sectors.

---

## Solution

The dashboard was designed to provide an interface for exploring ESG insights through four interactive pages:

### Overview
Provides a comparison of ESG performance across companies through quantitative and qualitative scores, company rankings, and interactive slicers.

### Sector Analysis
Allows users to compare ESG performance across sectors and identify sector-level trends and positioning.

### Company Analysis
Provides company-specific insights through ESG scores from different perspectives and normalised stock price trend.

### Portfolio Index
Displays the performance of an equal-weighted portfolio constructed from the selected companies using normalised stock prices, allowing users to evaluate the collective market performance of the selected ESG portfolio over time.

## Dashboard Design Principles

The dashboard was designed with the following objectives:

- Present ESG information in a clear and intuitive manner.
- Support exploratory analysis through interactive filtering.
- Enable comparison across companies, sectors, and portfolios.
- Combine quantitative and qualitative ESG perspectives within a single interface.
- Provide meaningful market context through stock price normalisation and portfolio tracking.
